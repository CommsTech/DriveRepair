# Open issues / gaps

1. No physical-disk validation (disconnection, power-loss, destination isolation, timeouts).
2. External rescue still Linux-only; Windows/macOS need equivalent safe acquisition paths.
3. Carving limited to PNG/JPEG; no filesystem-aware undelete.
4. No ddrescue/OpenSuperClone adapter yet.
5. Media-refresh engine intentionally not enabled.
6. Public release gates (signed builds, hardware matrix, license review) unmet.
